# Lolz Market Bot

Автоматизация покупки Telegram-аккаунтов на lzt.market, пересадки на новую
сессию и выставления на продажу. Управление — через Telegram-бота.

## Логика (пайплайн одного аккаунта)

1. Поиск лотов по фильтрам (цена, спам-блок, пароль, возраст сессии,
   происхождение: resale / autoreg / self_registration).
2. Покупка через Lolz Market API.
3. Подключение к купленному аккаунту напрямую по HEX (auth_key) + DC ID.
4. Получение кода для входа — сначала через API Lolz ("получить код"),
   если не выйдет — через чтение чата 777000.
5. Создание новой сессии.
6. Завершение всех остальных сессий (кроме новой).
7. Очистка аккаунта: все чаты/группы/каналы кроме Telegram (777000),
   контакты.
8. Проверка спам-блока через официальный @SpamBot (можно отключить).
9. Завершение купленной сессии — **только после** успешного выставления
   на продажу (чтобы не терять доступ при сбое).
10. Выставление на продажу с заданным шаблоном заголовка и ценой.

## Файлы

- `config.py` — переменные окружения и настройки по умолчанию
- `db.py` — Postgres (Neon): настройки, очередь, купленные лоты
- `lolz_client.py` — обёртка над Lolz Market API (через библиотеку lztmarket)
- `telethon_actions.py` — все операции с Telegram-аккаунтом через Telethon
- `worker.py` — фоновый цикл поиска/покупки/обработки
- `bot.py` — Telegram-бот управления (aiogram, кнопки под полем ввода)
- `main.py` — точка входа, запускает бота и воркер вместе

## Установка с нуля

### 1. Подготовь аккаунты и ключи

- **Lolz API-токен**: `lolz.team/account/api` → создать токен → права
  **basic, read, payment, market**. Доступ к Market API требует либо 200
  симпатий на форуме, либо отдельную платную подписку.
- **Telegram-бот**: `@BotFather` → `/newbot` → скопировать токен.
- **Свой Telegram ID**: узнать у `@userinfobot`.
- **api_id / api_hash**: `my.telegram.org` → API development tools.
- **База данных**: зарегистрироваться на `neon.tech`, создать проект,
  скопировать Connection string.

### 2. Залей код в GitHub

Загрузи все файлы из этого проекта в свой репозиторий (кроме `.env` —
его не должно быть в GitHub, он в `.gitignore`).

### 3. Разверни на Render (или другом хостинге с Python)

- New → Web Service → подключи репозиторий.
- Build command: `pip install -r requirements.txt`
- Start command: `python main.py`
- Environment → добавь все переменные из `.env.example` со своими
  значениями.

### 4. Запусти бота в Telegram

`/start` → появится меню с кнопками:

- **📊 Статус** — баланс на Lolz, очередь, последние покупки
- **🛒 Очередь покупок** — сколько аккаунтов купить (можно и убавить)
- **📥 Цена покупки** / **📤 Цена продажи**
- **📝 Шаблон заголовка**
- **⏱ Интервал поиска**
- **🎛 Фильтры поиска** — спам-блок, пароль, возраст сессии, вкл/выкл
  проверки через SpamBot
- **📦 На продаже** / **✅ Проданные** / **⚠️ Проблемные** — списки с
  карточками товаров (HEX/DC, цены, статус, кнопка изменить цену)
- **⏸ Пауза** / **▶️ Запустить**

### 5. Проверка

Поставь очередь на 1 аккаунт и проверь весь цикл вручную, прежде чем
ставить больше.

## Частые проблемы

- **401/403 от Lolz API** — проверь права токена (нужен именно **market**)
  и доступ к Market API (симпатии/подписка).
- **"The key is not registered"** — купленный аккаунт пришёл с уже
  нерабочей сессией (бывает у части дешёвых лотов) — бот такой аккаунт
  пропускает сам.
- **"Could not find a matching Constructor ID"** — устаревшая версия
  Telethon не знает новый формат данных от Telegram; `requirements.txt`
  уже указывает актуальную версию (`telethon>=1.40,<2`).
